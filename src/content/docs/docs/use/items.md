If you type "Lawn treatment, $65/application" more than twice, save it.
**Items** (in the account menu) is a reusable list of your products and
services that fills in invoice lines for you.

## Save an item

**Items → + New item**:

- **Name** and an optional description (the description flows into the
  invoice line).
- **Type**: **Service** or **Product**. Most trades and freelance work is a
  service; the choice keeps your sales sorted correctly behind the scenes.
- **Unit price**, a **unit** if you have one (hour, sq ft, visit), and a
  **default quantity**.
- Whether it's **taxable**, and at which of
  [your tax rates](/docs/use/send-an-invoice/), or leave it on the company
  default.

## Using items

On any invoice, estimate, or repeating schedule, the line's description box
*is* the item search. Type a few letters, pick the item, and the price,
quantity, unit, type, and tax settings land in the row. Adjust anything;
picking an item is a starting point, not a lock.

You can always ignore the list and type a one-off line by hand. (The **Top
products** report keeps an "Uncatalogued / other" row for exactly those.)

## Retiring an item

Prices move on. **Archive** takes an item out of the picker while keeping
its sales history; the [Top products report](/docs/use/reports/) still
knows what it earned. **Restore** brings it back, and you can import a whole
price list from CSV in **Settings → Import & export**.
